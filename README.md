# SurfaceRepair.in

Repair shop and small-business IT support website for SurfaceRepair.in (operated by A.S. Technologies, Mumbai).

## Docs

Live in the parent folder (docs repo):
- PRD.md
- DESIGN.md
- ARCHITECTURE.md
- DATABASE.md
- API.md
- AGENTS.md
- IMPLEMENTATION_PLAN.md

## Run locally

    pnpm dev

Open http://localhost:3000.

## Scripts

- `pnpm dev` — dev server (Turbopack)
- `pnpm build` — production build
- `pnpm lint` — ESLint
- `pnpm typecheck` — TypeScript check
